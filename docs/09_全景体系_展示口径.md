## D2. 6 层决策链（核心链路，展示口径）

**用户选择 3 件事（选产品 + 选平台/发布位 + 选目的）→ 系统自动调动 6 层 → 输出唯一 final_content_whitelist_id**

```
产品层(product_whitelist) → 平台层(platform_condition) → 内容策略层(content_strategy)
→ 内容结构层(content_structure) → 表达装饰层(expression_style) → 合规清洗层(compliance_cleaning)
→ 最终组装(final_whitelist ⭐)
```

💡 每层 = 一个"包"，每层都有候选池 / 正式池 / 冻结池 / AI Skill / 治理字段。所有层**结构同构**（字段 → 原子），差异在归属和用途。

## D10. 项目铁律与最终口径（定稿 · 不可偏离）

**铁律 4 条**：
1. 系统要活，但不能乱
2. AI 要强，但不能自作主张
3. 知识自动更新，但必须有证据和审核
4. 内容自动生成，但只能基于 final_content_whitelist_id

**最终架构口径**：Loom 是一个以产品知识、平台知识、内容策略知识为核心的 **AI 决策操作系统**。它通过：知识库 + Skill 编排 + 规则引擎 + 向量召回 + 人工审核 + 运行日志 + 反馈学习 + 成本治理 + 版本回滚，持续把产品、平台、内容、表现数据转化为**可复用、可解释、可审计、可优化的 final_content_whitelist_id**。
