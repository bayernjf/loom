## 3. 补齐模板（每个占位协议按此结构补）

```markdown
### PT-<名称>-<版本>
- 所属 WF / 段 / 调用的 Skill【内容待补】
- 输入与输出契约【内容待补】
- constraints（硬约束清单，含 Q 编号与 line 溯源）【内容待补】
- guards（准入/退出条件）【内容待补】
- 异常与降级路径【内容待补】
- 关联配置项（02 §C2）【内容待补】
```

### 模板示例（以已定稿 PT-PLATFORM-ADAPTER-V1.0 为例，内容来自 06 §2.3，完整模板效果）

| 模板项 | 内容 | 来源 |
|---|---|---|
| 所属 | WF-06 段7 平台适配 | 06 §1 |
| 输入/输出 | 输入=frozen PWS + 平台规则；输出=四态 allow/downgrade/block/pending_review | 01 段7 |
| constraints | 只读 frozen PWS；禁消费 pending PWC/PWS；禁输出成稿；**禁生成 final_id**；无 frozen PWS 返回缺失不造假 | line 2043 |
| guards | AI 输出一律 pending_review 需 HumanGate | 01 段7 |
| 异常/降级 | 动态信号一期=运营手工登记（Q37）；Skill 原型未启用，实现即首次落地 | Q37 |
| 关联配置 | 降级动作字典（Q38）、四维权重（Q34） | 02 |
