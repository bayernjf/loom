## 1. 仓库总览（✅ 选型定稿后）

- 技术栈（2026-09-13 负责人确认）：
  - 后端：**Python 3.12 + FastAPI**（模块化单体；包边界即 13 模块服务边界，未来可独立化）
  - ORM/迁移：SQLAlchemy 2.x + Alembic（以 10 Schema 为源）【库选择为工程建议】
  - 编排：**自研注册表驱动编排器**（YAML 声明式，数据驱动；见 runtime/）
  - 数据层：PostgreSQL 16 + pgvector / Redis 7（缓存 + Streams）/ S3 兼容对象存储
  - 前端：**React + Next.js + TypeScript**（管理后台 + 客户前端）
  - 中台对接：Python SDK + Webhook（middleplatform/）
- 顶层目录：

```

├── backend/              # 主后端（FastAPI 模块化单体，13 模块 → packages）
│   ├── app/
│   │   ├── product/      #   product-intake / modeling / dimension / atom / condition / whitelist-center
│   │   ├── platform/     #   platform-adaptation / platform-dynamic
│   │   ├── decision/     #   layer-strategy / compliance-center（进程内独立合规模块）
│   │   ├── final/        #   final-whitelist
│   │   ├── content/      #   content-manage
│   │   ├── feedback/     #   feedback-loop
│   │   └── core/         # 横切：skill7 通道 / writeAudit / RBAC / 配置中心 / SLA 引擎 / 模型注册表
│   ├── alembic/          # 迁移脚本（与 10 Schema 实体一一对应）
│   └── tests/            # unit / integration / contract / e2e（16 测试策略）

│   ├── skills/           #   <skill_id>/{definition.yaml, prompt/*.md, impl.py}
```
