## 1. 仓库总览（✅ 选型定稿后）

- 技术栈（2026-09-13 负责人确认）：
  - 后端：**Python 3.12 + FastAPI**（模块化单体；包边界即 13 模块服务边界，未来可独立化）
  - ORM/迁移：SQLAlchemy 2.x + Alembic（以 10 Schema 为源）【库选择为工程建议】
  - 编排：**自研注册表驱动编排器**（YAML 声明式，数据驱动；见 runtime/）
  - 数据层：PostgreSQL 16 + pgvector / Redis 7（缓存 + Streams）/ S3 兼容对象存储
  - 前端：**React + Next.js + TypeScript**（管理后台 + 客户前端）
  - 中台对接：Python SDK + Webhook（middleplatform/）
- 顶层目录：


## 2. 可执行物落位（数据驱动，runtime/）

### 2.1 Workflow（WF-01~12）
- 落位：`runtime/workflows/WF-01.yaml ~ WF-12.yaml`（YAML 声明式，注册表演绎执行）
- 内容：所属段 / Skill 序列 / 人工 Gate 插槽 / 输入输出 Schema 引用（06 §1）
- 映射约束：段-WF 接缝按 Q72（段8→WF-06、段2→WF-01、段13→WF-11+12），**不新增 WF**

### 2.2 Skill（50+ 注册表）
- 落位：`runtime/skills/<skill_id>/`（每个 Skill：定义 yaml + prompt 模板 + 实现）
- 注册表 11 字段（06 §4.1）：skill_id / layer / input-output_schema / 依赖知识 / 模型档位 / 阈值 / 失败策略 / 审核规则 / 成本上限 / 版本
- 实现约定：**Critical Skill 输出必走 skill7 候选通道**（ai_suggested→pending_review→…，line 11314）；历史 SkillRunLog 不可 mutate

### 2.3 Agent（3 个）
- 落位：`runtime/agents/AG-REVIEW-COPILOT / AG-PM-AUDIT / AG-SUPPORT`
- 必带字段：max_turns + max_tokens + emergency_stop（line 2115）
- 边界：**不授予任何 owner/审批角色**（Q66）；AG-SUPPORT 上线前需脱敏审核

### 2.4 PT 协议
- 落位：`runtime/protocols/PT-<名称>-<版本>.md`（对齐 12 文档清单）
- 实现前状态：已定稿 7 个可编码；占位协议补齐后（12 §3 模板）方可编码
