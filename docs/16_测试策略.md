### 2.3 状态机非法迁移（13 迁移表）

- 每台状态机一组：**终态接收事件 → 拒绝**；无权限角色执行红线迁移 → 拒绝（RBAC 断言）
- 重点：PWS revoked 后立即断消费（Q32）；PWC 冷却 14 天回待用（Q24）；atom 解冻不重审（Q20）

- effect-callback：请求体字段缺失 → 400；未授权 Key → 401；同 content_id+captured_at 重复推送 → 幂等覆盖 200；孤儿 content_id → 进孤儿队列

## 4. 质量门槛与数据（建议）

- 覆盖率目标：核心规则层（评分/权重/Guard/状态机）≥ 90%；全系统 ≥ 70%【建议】
- 测试数据：每租户独立 fixture；跨租户断言不可见（Q33）
- Mock 策略：外部 Agent 推送（effect-callback）mock；平台数据（catFeedback）用样例集；**禁止用生产数据**
