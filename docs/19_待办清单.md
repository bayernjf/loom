## 清单一：要填什么（给业务方 / 运营 / 内容团队）

> 核心结论：出第一张真 `final_id` 要的是**两个人 + 四样数据**，不是一份大模板。最贵的人工打分不必首批索取。

### 两个人
- **录入人**：填下面「四样」。
- **跑链裁决人**：按 docs/21 SOP 走 段1→6→10 并在 Gate 裁决，产出 PWS 冻结 + 合规清洗报告（Guard①②⑦）。没人跑链，第一张证出不来，且工程自造数据不作数（违反禁臆造红线）。

### 四样数据（按依赖顺序，全部 `status=active` 即可，不看 `gate` 档）
| # | 什么 | 谁给 | 必填到什么程度 | 卡不卡发证 |
|---|---|---|---|---|
| 1 | 一个真产品（段1 intake → ProductSpace） | 业务/运营 | 1 个真实产品 | 卡（其余都挂在它上） |
| 2 | 1 个发布位 `platform` / `code` / `name` / `slot_type` | 运营（值业务定） | `slot_type` 类型名业务方给（旧 13 类目录已丢失，工程不得编） | 卡，只查 `status=active` 且 `platform` 一致 |
| 3 | 该 产品×平台 建 1 条 PCP | 运营 | 只选 `{platform, template_code}`（4 套模板已播种，不填权重） | 卡，无 active PCP → 409 |
| 4 | 三包 CSP / CSTP / CEP 各 1 条 | 业务/内容 | 定键见 docs/19 §3（CSP 6 键 / CSTP 1 键 / CEP 4 键） | 卡（Guard③） |

### 可以留空、不卡发证（别为这些等工期）
- 发布位四维分 `traffic` / `safe` / `conv` / `load`、`risk`、`source_url`、长度/时长、`gate` 档；
- `fit` 权重矩阵（缺了只是 `score_incomplete`，Q54 定死评分仅排序不做门槛）；
- `slot_type_defaults`（V2 才消费）。

### 两个坑
1. 敏感领域字典 `cp_law_sensitive_domains` 是零行种子 ⇒ Guard⑥ 默认放行是**可配置项非永久豁免**。首批选产品请有意**避开**拟启用为敏感类目的行业，否则会挂在等法务。
2. 模型选择拆两次：先用 synthetic 打通（不花钱），"真 agnes 全链"另立点工（ATOM-AFFINITY 至今 synthetic，绑一起只会都变慢）。

### 自检 & 回填工具（Q210 / 02 C1.154）
- 填完跑 `python backend/scripts/check_master_data.py`（可 `--json`）看还差哪类 active 数据；只读、与发证解析器同口径、不进 CI。
- 骨架 `backend/scripts/seed_master_data_template.py`：`CONFIG` 全 `<REPLACE_ME_...>` 哨兵，未改完会中止（防占位符入库）；`--demo` 跑通机制、`--dry-run` 只打印。
- **判定「首批完成」唯一标准**：真实部署库出现一张 `final_id`，六路材料与 `fcw.issued` 审计指向**真实业务数据**，非测试夹具/工程臆造。

## 清单二：要裁决 / 拍板什么（给负责人）

### 1. 网关与 TLS 归属（部署侧，可上线未达标的根因之一）
- "后端在网关后"是 private beta 前提（Q144），但仓内至今无产物。需负责人定：网关由谁提供、TLS 终止在哪层。不裁决则 ③ 可上线永远不达标。

### 2. 首批主数据（真正要的是两个人，不是两张表）
- 业务方按 docs/19 §0.2「最小可发证清单」回填四表；另需指定**跑链裁决人**把 段1→6→10 跑一遍并在 Gate 裁决。工程侧不得代填（禁臆造红线）。这本身就是负责人要协调的资源调度，不是工程任务。

### 3. V2 第一项：客户侧真实认证与 actor↔tenant 绑定
- Q178 只做了内部 `loom_staff_` 令牌；客户口仍按声明 `tenant` 过滤，属已接受风险（Q200 #32 执行级闭合但默认门控关时仍自报）。何时做由负责人排期。

### 4. docs/08 §2.2 排期三列（工期 / 人员 / 起止）
- 原文未给，须负责人提供资源信息，禁止倒推编造。

### 已经结掉的（勿重复列为待办）
- **#32 多租户隔离**：执行级闭合（Q200/Q202 验证五口 404、discard 403）。
- **#33 默认发布形态**：5432/6379/9000-9001 绑 127.0.0.1、口令 env 化、空 `LOOM_MASTER_KEY` fail-fast（Q200/Q203）。
- **#34 治理不变式**：`final_id` 唯一出口有运行期守卫（Q203 `exit_guard.py`），发证两口无条件要 `loom_staff_` Bearer。
