## §5 E2E 边界与已知限制（验证时避开/特殊处理）

1. **三条产品边界**（README §1.3，V1 设计如此，不是缺陷）：受控 private beta（无公网自助注册）；客户侧无登录（只吃 `?tenant_id=`）；花钱与生效逐单过人（自动补足/真视频/改 Prompt 均 env 门控默认关）。
2. **真模型/真供应商链路**默认关：synthetic 替身模式可验全流程；真花钱链路需 `LOOM_MASTER_KEY` + 打开门控 + 供应商容量（当前供应商视频队列实测 503 满，见 handoff 外部输入清单）。
3. **真 ACME / 现网部署未证**（复判③未达标）：浏览器 E2E 在本机 dev 形态（localhost:3000）做，不涉及网关 TLS。
4. **运行期强校验待点工**：段3 运行期强校验、段9「选料只能从字典选」的运行期校验仍随点工（docs/09 Q310 口径）——E2E 到这两处按"当前可实现行为"验证，不按 PRD 终极口径。
5. **UI 元素级步骤**未固化：本文档操作路径到"页面/入口"粒度；执行时先 `bu.snapshot()` 定位元素再操作，元素命名以实测为准。
