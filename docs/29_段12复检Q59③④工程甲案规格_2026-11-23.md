## 2. ③ 施工指令核对（`review_hits["construction"]`）

| 检查 | 机械口径（v0.1） | 命中 code |
|---|---|---|
| 降级映射已执行 | ①词库产出的 `downgrades` 词条若仍原样出现在正文（大小写不敏感），说明降级建议未被施工 | `downgrade_not_applied`（word/entry_id） |
| 结构指令已落实 | CSTP `payload["struct"]` 非空时，正文按换行切段，段数 ≥ 结构部件数（"钩子-论点-收尾"＝3） | `structure_not_applied`（expected/paragraphs） |
| 无证外产品事实 | 确定性承诺词表（保证/根治/100%/百分百/绝对/第一/唯一/零风险/无副作用/永久/包治）在正文出现且不在 PWS 原子 `content+aliases` 证据文本中 | `unverified_claim`（word） |

无法机械判定的表达维度（CEP 的 tone/perspective/explicit/soften）列入
`unchecked`，不臆造判定。claims 明细一并返回（word + matched_in_pws）。

## 3. ④ 国家规则核对（`review_hits["country_rules"]`）

| 检查 | 机械口径（v0.1） | 命中 code |
|---|---|---|
| 外链 | 正文提取 http(s) URL；命中目标国家外链提示（CN：站外链接需按平台外链规则确认） | `outbound_link`（urls） |
| 留资 | 正文含电话/手机号/微信/私信/邮箱/二维码/扫码等引导词；CN 提示个保法告知，EU 提示 GDPR 告知 | `lead_capture_notice`（words） |
| CTA | CEP `payload` 含 `cta` 指令而正文找不到 CTA 词（立即购买/下单/预约/领取/报名/咨询/购买/点击），记指令未落实 | `cta_not_found` |

国家规则集为 v0.1 工程种子（CN / EU 主要国家 / 其余 generic），字段记
`rules_version="v0.1-engineering"`，待业务方/法审校准；`platform_rules` 表
（04 §2.13 平台位 blocked/partial）语义是平台位可选性，不是文案规则，本切片
不复用它，避免混淆两套口径。

- 不做真实语义判定（tone/perspective 只登记 unchecked）；
