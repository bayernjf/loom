## 1. 要解决的问题

Q44 在 docs/25 长期标 ⬜，缺口是「仅字典表有 `ratio_min`/`ratio_max`，没有近 30 天分布聚合、没有健康度栏目」。运营看不到“最近实际发出去的内容目的结构”与 Q25 配比上下限的偏差，只能在字典页看静态数值。

本轮把“发起侧结构”做成可观测面板：

- 统计近 30 天**已签发 FCW** 按 `goal` 的数量；
- 与 Q25 字典当前 `ratio_min`/`ratio_max` 对比；
- 只对越界项出黄色软提示，不拦签发按钮、不改 Gate、不写审计。

## 2. 口径（实现口径，非 owner 新拍板）

| 项 | 口径 |
|---|---|
| 计数源 | `final_content_whitelists` 中 `publish_status='published'` 的发证行 |
| 计数含义 | 近 30 天**发起了哪些目的的内容**，不是效果回流条数 |
| 默认窗口 | 近 30 天（含今天），半开区间 `[from 00:00, to+1d 00:00) UTC` |
| 租户/空间 | `tenant_id` 必填；`product_space_id` 可选收窄 |
| 分母 | 窗内全部已签发 FCW |
| 目的行 | 只返回当前 `status='active'` 的 Q25 字典项 |
| 归档目的历史码 | 不单列成目的行；计入 `total`，另以 `unmapped_count` 单列 |
| 健康五态 | `no_data`、`unconfigured`、`below`、`within`、`above` |
| 浮点边界 | 容差 `1e-9`；恰好 40%/15% 判 `within`，不制造假超标 |
| 报警 | 仅 `above`/`below` 生成前端黄条；`no_data`/`unconfigured` 只显示灰态 |
| 页面归属 | 任务页 `/admin/fcw/assemble` 常驻面板＋段13 `/admin/effects` 健康度栏，双落为本轮实现口径；owner 此前只确认“做 Q44”，未单独拍板页面归属，后续若要单页归属，收窄前端挂载即可，后端接口不变 |

## 7. 已知边界

- 页面归属为**实现口径双落**，不是 owner 新拍板；owner 若要求只保留任务页或只保留段13，删一处挂载即可，后端不需要改。
- “近 30 天”按 `created_at`（发证时间）而非 `published_at`；已签发 FCW 的 `created_at` 与发证动作同时写入，当前无回填场景。
- 目的行只展示 active 字典项；若运营归档某目的，其在窗口内的历史发证仍计入分母与 `unmapped_count`，不出现在目的行。
- 配比默认值是 PRD 明示的 5 个单边界；“未给另一边”不是缺数据，健康判定会按已配置的单边界单向判断。
