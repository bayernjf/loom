## 路 2：现网部署 → ③ 翻达标

- 出处：docs/17_部署与运维.md §1.3 投产最小清单 + Q318 部署执行前检查单；制品已落 `infra/docker-compose.gateway.yml`／`infra/caddy/Caddyfile`／`infra/gateway-rehearsal.sh`（23 断言）
- 归属：运维／服务器负责人

### 等什么（一项硬件 + 一项配置，其余全在仓内）

1. 一台公网主机（DNS `A` 记录指向、宿主 **80/443 可达**；80 仅用于 ACME 签发与 308 跳转）；
2. `infra/.env` 三个必填：`POSTGRES_PASSWORD`／`MINIO_ROOT_PASSWORD`／`LOOM_MASTER_KEY`（缺任一个起不来）；`LOOM_GATEWAY_DOMAIN` 与 `LOOM_PUBLIC_BASE_URL` 已设且**同域**（异域预检 `exit 2`，Q287）。

### 找谁要（可直接转发）

- 把 docs/17 Q318「部署执行前检查单」9 条原样转给运维，部署机照单打勾；服务器/域名到位后通知工程侧执行（工程侧零裁决、零新增）。

### 要回来后做什么（一条命令起栈 + 预检 + 身份引导，顺序不可反）

1. 起栈：`cd infra && docker compose --env-file .env -f docker-compose.yml -f docker-compose.gateway.yml up -d`（迁移自动跑；宿主只剩 80/443）；
2. 跑 `infra/gateway-rehearsal.sh` 预检 **23/23 PASS**（本机 localhost＋内部 CA 可先跑，不碰 Let's Encrypt 速率限额）；
3. 三 curl 验收：首页 200／`/docs` 404（网关拦）／http→https 308；
4. **真 ACME 证书签发**（Let's Encrypt 真签，落命名卷 `caddy_data`/`caddy_config`；卷丢重签撞速率限额）；
5. 引导内部身份（鸡生蛋，Q178）：门控**保持关**→ `POST /api/admin/staff-keys` 签首个人员令牌（明文仅返回一次）→ 浏览器 `/admin/login` 粘贴（经 `/api/auth/me` 自检写 cookie）→ `.env` 设 `LOOM_STAFF_AUTH_ENABLED=true` 重启 backend；
6. 备份确认：`db-backup` 每日 `pg_dump`＋7 天保留（`infra/docker-compose.yml:123`）；监控按需叠 `monitoring` profile（需 `LOOM_GRAFANA_ADMIN_PASSWORD`）。

**必须显式知晓（清单解决不了的三条，docs/17 原文）**：客户侧没有登录（客户读口只吃 `?tenant_id=`、零认证依赖）；前端客户侧非多租户（固定 env `LOOM_TENANT_ID`/`LOOM_ACTOR_ID`）；公网自助多租户 SaaS 已裁 NO-GO（Q144）。部署翻的是「③ 可上线」，不等于开给多客户自助——那是路 3（V2 第一项）。
