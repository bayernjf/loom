## 2. 四块缺口清单

### ① 分段编目（业务方）
- **缺口**：屏3 只读切分 FCW 脚本文本，无「分段实体」（时长/镜头/转场）；可编辑能力标注「随段12 规格到位后开放」。
- **要什么**（逐条给取值/格式/约束，标 P0/P1）：
  - 分段粒度：句子／场景／镜头（三选一或组合）；
  - 分段元数据字段建议：`segment_id / content_id / seq / start_ms / end_ms / type / source_leaf / text`（可增删，字段名业务方可定）；
  - 是否允许人工编辑分段：改文本→重生成（走既有生成链路） vs 只改分段元数据（不动 body）；
  - 编辑后是否重跑 CCR 复检（屏4 口径）。
- **落地动作**（规格到位后）：分段实体表＋CRUD＋屏3 编辑化＋复检联动。

### ② 语音转写／字幕（供应商）
- **缺口**：成片无 CCR 可喂文本（design-video-studio-segment-cleaning.md §1.4）；屏4 复检对象目前是脚本文本。
- **要什么**：
  - 转写能力来源：agnes（或指定供应商）`video → transcript` 接口文档——是否可用、入参/出参、语种支持、时长上限、异步/同步；
  - 产物形态：SRT／VTT／纯文本／JSON；
  - 转写与 FCW 脚本文本的关系：覆盖／并存（各标来源）／仅作回退。
- **落地动作**：转写任务接入＋屏4 复检对象切换/并存＋复检留痕来源。

### ③ 对象存储（供应商／工程）
- **缺口**：视频原片／转码存储载体与访问口径未定。
- **要什么**：
  - 存储载体：沿用仓内 MinIO（infra compose 已含） vs 指定外部对象存储服务；
  - 存储形态：原片 vs 转码（清晰度档位）；
  - 访问控制：管理端可见/客户可见；URL 是否时效签名（签名过期时长）。
- **落地动作**：上传/归档/下载链路＋访问口＋审计。

### ④ 成片复检（业务方）
- **缺口**：视频专用复检规格（检测类型/处置）未定（段12 视频复检规格【待补】，Q323 起挂账）。
- **要什么**：
  - 复检对象：转写文本／字幕／脚本文本（三选一或组合）；
  - 检测类型：沿用段5 已有 8 检测名单（design-d3.5 §3.3 定稿） vs 新增视频专用检测（画面 OCR／语音敏感词等，需给名单与判定规则）；
  - 处置：阻断发证 vs advisory；沿用 CCR 人工 approval 还是独立 Gate。
- **落地动作**：视频复检场景注册（模型网关新场景或规则引擎扩展）＋屏4 扩展。

## 4. 完成条件与点工清单

- **完成条件**：四块全部回填且可复核（禁臆造），任何一块未回填则该块维持【待补】挂账、不提前点工。
- **点工清单**（规格到位后，互不依赖可分批）：
  - ① → 分段实体＋编辑化；
  - ② → 转写接入；
  - ③ → 存储链路；
  - ④ → 视频复检；
  - ②＋④ 齐备后 → 屏4 复检对象切换为成片文本化产物（当前脚本视图保留为回退）。
