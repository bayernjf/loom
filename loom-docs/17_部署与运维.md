## 1. 环境与发布

| 环境 | 用途 | 数据 | 说明（建议） |
|---|---|---|---|
| dev | 开发联调 | 样例数据（16 测试数据） | 本地/单实例 |
| staging | 验收 + Evaluation Dataset 回归 | 脱敏数据 | 发布前闸门 |
| prod | 正式（SaaS 多租户） | 生产数据 | 隔离实例或强隔离 |

- **CI/CD 流程**（建议）：提交 → 单元/契约测试（16）→ 构建 → staging 部署 → Evaluation Dataset 回归（防红旗 S2"Skill 从未运行"）→ 人工 Gate → prod
- **版本与回滚**：应用版本 + PWS/FCW 快照版本分离；回滚中心（09 D3.12 Rollback Center）覆盖模板/原子/规则/Skill/Prompt
- **发布纪律**：AI 相关变更（Skill/Prompt/权重）必须可回滚、可审计（A4 Prompt 治理 + Q63 KUP 回滚）

## 3. 密钥与安全

- 密钥管理：API Key 一 Agent 一 Key 可吊销（Q60b/Q67）；**密钥不入库、不进文档**（本项目 AGENTS.md 红线）
- 访问控制：RBAC 8 角色 + 权威扩展（07 §2.3）；红线操作（PWS 冻结/原子正式化/合规废弃/Prompt 修改）= 角色 + 人工 Gate（line 7674）
- 审计：writeAudit append-only（所有人工操作 + AI 调用）
- 外部回调安全：effect-callback 鉴权 + 限流 + 幂等（11 §2.1/§3）
- 脱敏：AG-SUPPORT 上线前脱敏审核（Q66）；staging 数据脱敏

## 5. 备份与恢复（建议）

- 数据备份：关系库每日全量 + WAL 增量；对象存储（素材/成品）跨区冗余
- 快照不可变：PWS/SkillRunLog/审计 append-only，备份需支持历史版本追溯（Q31 全保留）
- 灾难恢复：RPO ≤ 24h / RTO ≤ 4h【建议】，随 V2/V3 客户规模收紧
